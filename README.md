# iBITS Portal

A web portal for managing student organization data, finances, events, and help desk tickets.

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- MySQL (XAMPP)
- JWT for Authentication

## How to Run Locally
1. Start Apache and MySQL in XAMPP.
2. Ensure the `ibits_portal` database is created.
3. Run `npm install`
4. Run `npm run dev`
5. Open `http://localhost:3000`
